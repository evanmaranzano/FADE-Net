01

项目理解摘要

FADE-Net（Feature-fused Hybrid Attention Distribution Estimation Network）轻量级面部年龄估计框架，MobileNetV4-Small 骨干，集成 DLDL-v2、MSFF、SPP + 5 个可选创新模块。

模块文件描述
网络架构model.pyLightweightAgeEstimator + CoordAtt + SPP + 纹理/频域/MoE
训练循环train.py + cli.pyAMP、EMA、MixUp、断点续训、消融开关
数据管线dataset.pyAFAD 加载、分层分割、LDS 权重、SafeRandomErasing
损失函数utils.pyCombinedLoss（7 种损失）、LossOutput namedtuple
推理评估evaluation.pyTTA（raw/flip/multi）、predict_probs
实验管理experiment.pymetadata 指纹、checkpoint 兼容性、安全加载
骨干适配backbones.pyMobileNetV4-Small/RepViT/MobileNetV3

07.5

补充审计（2026-05-31）

二次审查发现原始报告中 3 项修复存在实现偏差，已全部纠正。

问题原始声明实际偏差修复
P2_DERIVED_ATTRS mutation trackingfrozenset 仅定义无运行时效果，未阻止外部修改加 __setattr__ 触发 UserWarning + _allow_derived_set flag；发现 from config import Config vs from src.config import Config 产生不同类对象，改用 type(config) 解决
P2.item() 延迟到 epoch 末仅 train_loss 延迟，train_mae_sum 仍每 batch 调用 .item()train_mae_sum 改为 tensor 累积，epoch 末统一 .item()
P3所有依赖添加版本下限/上限thop 和 python-docx 漏掉版本约束补 thop>=0.1.1、python-docx>=1.0，全部 20 个依赖均有约束
关键发现：from config import Config 和 from src.config import Config 在 Python 中加载为不同类对象（id() 不同），导致 class-level flag 不共享。解决方案：所有 flag 操作改用 type(config) 直接操作实例的实际类。

受影响文件（补充修改）：config.py、model.py、experiment.py、dataset.py、train.py、requirements.txt、scripts/audit_paper_results.py、tests/conftest.py、tests/test_paper_result_audit.py（共 9 个文件）

08

风险说明

Validation TTA flip 模式：best model 选择基于 flip MAE，如需复原改 mode="multi"。
EMA 解冻后 shadow：初始值为当前权重非历史均值，长期训练影响可忽略。
LossOutput namedtuple：完全向后兼容 tuple 解包，所有现有代码无需修改。
.item() 延迟：train_loss 和 train_mae_sum 均为 tensor 累积，epoch 末才统一 .item()。消除了训练循环中所有 CUDA 同步点。
conftest.py seed：autouse=True 对所有测试生效。同时抑制测试中 derived attr 变更的 UserWarning。
logging 模块：FileHandler 写入 TensorBoard 同级目录 train.log，不影响控制台输出。
_DERIVED_ATTRS __setattr__：仅 warn 不 error，生产代码中 authorized 赋值通过 type(config)._allow_derived_set = True 跳过。测试中通过 conftest fixture 自动抑制。
